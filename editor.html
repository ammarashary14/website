Publish your changes

  1. Preview your page, then choose Download index.html.
  2. Open GitHub’s upload page and sign in.
  3. Upload the downloaded file as index.html, replacing the old one, and commit to main. Rename it first if your browser added a number to the filename. GitHub Pages will update once enabled.

This editor does not ask for a password or GitHub token. Saving a draft or downloading a file does not change the live website.
